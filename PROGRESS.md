## Decisions
- Pure `resolve()` returns steps; engine executes them (state steps shared via `applyStep`, so tests need no DOM).
- Saves after every state step; transient scene flags are cleared on load. Interrupted storm -> quarters, access granted, `finalSequence` kept so the exit stays blocked.
- Close-up labels are HTML chips (readable on phones); traces are painted into the board PNG.
- Sprites are generated by pose routines then frozen to palette-indexed strings, not hand-typed.
